# Structured Constraint-Driven LLM Execution Framework

A document- and role-based execution framework for reducing constraint drift and hallucination in long-running LLM-assisted workflows.

**Author:** Yeming Dai  
**Status:** Pre-v1.0 — formalization in progress

## Current publication

- [中文正文](structured-llm-execution-framework-zh.md)
- English version: planned for the v1.0 formalization process

## Provenance

This project was originally developed and iterated in the author's [`smter6626/sharable`](https://github.com/smter6626/sharable) repository before being split into this dedicated repository in August 2026. Earlier development history remains preserved in the original repository.

- [Original Chinese article in `sharable`](https://github.com/smter6626/sharable/blob/main/structured-llm-execution-framework/structured-llm-execution-framework-zh.md)
- [Earlier commit history for the article](https://github.com/smter6626/sharable/commits/main/structured-llm-execution-framework/structured-llm-execution-framework-zh.md)

From the repository split onward, this repository is the canonical home for the framework's formal versions, citation metadata, releases, and planned DOI-backed publication.
