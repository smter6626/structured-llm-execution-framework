# Repository-Native Execution Governance for Long-Running LLM Workflows

> A Structured, Constraint-Driven Governance Methodology for Durable Contracts, Runtime State, and Evidence-Backed Transitions

A repository-native execution-governance methodology for auditable long-running LLM workflows. The methodology separates durable project contracts, current authoritative runtime state, and optional long-horizon history; it also defines role boundaries, evidence-backed transitions, explicit supersession, and proportional rigor.

Version 1.2 is the current canonical bilingual publication of the methodology. It refines independent review as independent evidence access, verdict formation, and evidence-sufficiency judgment; makes explicit supersession more precise; and separates observed practice, derived methodology, conceptual positioning, and proposed extensions.

The reported cases demonstrate applicability and traceability in human-mediated workflows. They do not establish quantified causal improvement, comparative superiority, peer-review status, production adoption, or implemented fully autonomous orchestration.
