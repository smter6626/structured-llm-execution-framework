# Repository-Native Execution Governance for Long-Running LLM Workflows

> A Structured Constraint-Driven Framework for Durable Contracts, Runtime State, and Evidence-Backed Transitions

A structured constraint-driven LLM execution framework for reliable, auditable multi-step workflows. The framework separates durable project contracts, current authoritative execution state, and optional long-horizon history, with evidence-backed state transitions and explicit decision supersession.

**Author:** Yeming Dai  
**Status:** v1.0 candidate
